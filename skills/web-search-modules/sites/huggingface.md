# Hugging Face — huggingface.co

**Used by:** academic-papers, benchmarks, model-releases
**Reachable:** yes

## Query
- Papers: `site:huggingface.co/papers <topic>` — daily/monthly trending ML/AI papers with community upvotes.
- Org repos: `https://huggingface.co/<org>` lists an org's repos. Commit history, revision tags, and README diffs are ground truth on what changed, including silent re-uploads that never got an announcement. Verified: `https://huggingface.co/deepseek-ai`.
- Leaderboards: Spaces hosting leaderboards and model cards with an eval table. Verified: `https://huggingface.co/spaces?category=model-benchmarking`, `https://huggingface.co/spaces/ArtificialAnalysis/LLM-Performance-Leaderboard`.

## Worth knowing
- Leaderboard aggregation has largely consolidated here as standalone trackers shut down — the original Open LLM Leaderboard retired in 2026.
- For open weights, prefer the repo commit log over the announcement — weights get quietly re-uploaded and the README edited in place.
