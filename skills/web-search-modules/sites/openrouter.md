# OpenRouter — openrouter.ai

**Used by:** benchmarks, pricing
**Reachable:** yes

## Query
- Pricing: `https://openrouter.ai/models` — per-token prices side by side across vendors. Good for building a comparison set fast.
- Usage: `https://openrouter.ai/rankings` — actual usage share by model, answers "what do people really run" in a way no benchmark does.

## Worth knowing
- It's an aggregator, not the authority — verify each figure at its own provider's pricing page before quoting it.
